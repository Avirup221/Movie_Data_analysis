# Movie_Data_analysis
In this project we analysed the Netflix Movie data set and get inside about the Different questions.
## About The Data set
Netflix is known for its work in data science, AI, and ML, particularly for building strong recommendation models and algorithms that understand customer behavior and patterns. Now i have a dataset of more than 9,000 movies. I need to solve the following questions to help the company make informed business decisions accordingly.
## Question which are asked here
1)What is the most frequent genre of movies released on Netflix?

2)Which has highest votes in vote avg column?

3)What movie got the highest popularity? what's its genre?

4)What movie got the lowest popularity? what's its genre?

5)Which year has the most filmmed movies?
